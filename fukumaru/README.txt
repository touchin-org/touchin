TOUCH IN / NFC動画再生ページ

中身：
 index.html  動画ページ
 video.mp4   受け取ったMP4（約11MB）
 poster.jpg  動画から抽出したサムネイル

GitHub Pagesで公開する手順：
1. 自分のGitHubアカウントで新しいリポジトリを作成します（公開範囲に注意）。
2. この3ファイルをリポジトリの最上位にアップロードしてコミットします。
3. Settings → Pages → Deploy from a branch → main / (root) を設定します。
4. 公開されたURLをスマホで開き、再生できるか確認します。
5. NFC Toolsなどのアプリで、NFCカードへURLのNDEFレコードを書き込みます。
6. iPhone/Androidでカードにタッチしてテストします。

注意：
・インターネット接続が必要です。
・GitHub Pagesの動画はURLを知れば第三者にも閲覧される可能性があります。公開前に権利者の許可を確認してください。
・動画の自動再生はスマートフォンで制限されることがあります。現在は確実性を優先したタップ再生です。
・NFCカードにはMP4自体でなく公開ページのURLを書き込みます。
